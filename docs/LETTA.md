# LETTA 方案（S6：让她自己长）

> 状态：**试运行中**（2026-10-30 起）。本文是方案 + 操作手册 + 风险清单，随试运行更新。

## 1. 一句话

把「她是谁」从**我们写的提示词**，改成**她自己能改写的状态**：人格、对主人的认识、记忆块都放在 Letta 里，
由她自己用工具改；我们只保留安全的红线、动机（什么时候想说话）和接入层（QQ）。

## 2. 为什么不是「加更多记忆」

| | 现在的原引擎 | Letta |
|---|---|---|
| 人格 | 6 份写死的 prompt + 界碑 + 规矩，受保护 | 记忆块 `persona`，**她自己能改** |
| 记忆用途 | 材料：查到了就塞进上下文 | 工作状态：直接影响她下一句怎么说 |
| 遗忘 | 摘要压缩 + 语义记忆衰减 | 她自己决定记什么、改什么 |
| 主动性 | 内置动机（冲动/配额/静默/承诺） | 没有，得外挂 |
| 可解释性 | `trace.jsonl` 每一步都有 | 只有记忆块的 diff |

结论：**她「像不像一个人」由 Letta 负责，「什么时候想开口」仍由我们负责。** 两边分工，不互相替代。

## 3. 架构

```
QQ ── NapCat(云端 3001) ── 桥(qq-bridge.mjs)
                              │
              ┌───────────────┴────────────────┐
              │ behavior.letta.convs 命中？      │
              └───────┬───────────────┬────────┘
                   是 │               │ 否
                      ▼               ▼
        cloud/lib/letta.mjs      原引擎（pet-api + scheduler）
                      │
        SSH 反向隧道 127.0.0.1:8283
                      │
              本机 Letta server（agent-7c89ac1b）
              ├─ blocks: persona / human / memory / safety(只读)
              ├─ 工具: memory_insert / memory_replace / conversation_search / send_message
              ├─ LLM: DeepSeek（OpenAI 兼容端点）
              └─ 向量: ollama bge-m3（本机）
```

要点：

- **会话白名单**：只有 `convs` 里列出的会话走 Letta，其它一律原引擎 → 可以只开一个群、或只开私聊。
- **回落**：Letta 超时/报错/隧道断，桥记一条警告后回原引擎，不会「没回」。
- **群聊主动插话**（S2）试运行期间关闭，避免「两个声音」。
- 反向隧道只绑服务器回环，**不暴露公网**，也不需要开放任何入站端口。

## 4. 记忆怎么灌（seed-cloud.py）

从云端拉：`memory.json`（私聊 196 + 群聊 619 条）、`semantic.json`（100 条热搜/空间）、`profiles.json`、`commitments.json`、`self.json`。

压成 898 字的 `memory` 块，结构：

```
【我记着的事】（来自云端那份我，截至 10-30）
私聊 N 条，群聊 M 条，跨度 …；群号 …
群里常说话的人：- 名字：N 条，平均 X 字 …
最近几轮群聊（我确实说过的）：群友说：… → 我回：…
我刷到过的热搜：…
承诺：兑现 X 条，没做到 Y 条
旧的我这样形容自己：…
```

清洗规则（`rebuild-digest.py`）：剥掉注入前缀（`【群聊】说话的是…`、`【这个会话里刚发过的图】`）、只留 `assistant` 与清洗后的 `user` 配对、取最近 10 轮。
——第一版没清洗，结果她把「说话的是群友 X」当成自己记忆背下来了，这个坑记一笔。

### 5.3 怎么确认「是谁在回」

```bash
sudo grep -E 'Letta|回复：' /opt/dsh-pet/logs/bridge.log | tail
```

- 走 Letta：`Letta 回复：…`
- 回落：`Letta 没接上，回落原来的大脑`

### 5.4 怎么关掉

把 `behavior.letta.enabled` 改成 `false` 并重启；或在 `convs` 里删掉落那个会话。**数据不动**，随时可以再开。

## 6. 风险与已知问题

| 风险 | 现状 | 对策 |
|---|---|---|
| 她把自己改坏 / 改飘 | 无审计、无回滚 | **下一步必做**：块变更留痕 + 快照回滚 |
| 把群友的玩笑当真写进记忆 | 无写入闸 | 抄我们原引擎的 `guard`：可疑句不落盘 |
| PC 关机 / 隧道断 | 回落原引擎 | 明确提示 + 日志；长期需上云或做成本机服务 |
| 群里话多 | 12 分钟追问窗口 | 可降到 4 分钟，或只认 @/引用 |
| 成本 | 8–13k tokens/轮 | 关掉 `conversation_search` 频次、缩短 memory 块 |
| 两套记忆不同步 | 故意 | 切换前跑一次「记忆合并」 |

## 7. 分阶段计划

- **P0（已完成，今晚）**：本机跑通、云端记忆灌入、30 轮 + 2 次巩固、QQ 私聊/群聊试运行接线。
- **P1（已完成，2026-10-31）**：**审计与回滚**。见下面「9.1 审计怎么用」。没有这道闸，长期演化不能开。
- **P2（已完成，2026-10-31）**：**动机接入**。见下面「9.2 动机接入怎么工作」。
- **P3（3–5 天）**：**决定主脑**。若试运行满意 → 云上常驻（或本机常开）+ 记忆迁移 + 关闭原引擎的人格路径；
  若不满意 → 保留原引擎，Letta 只作为「私聊里的另一个她」。

## 8. 判断标准（试运行看什么）

不看「她说话像不像人」（那太好演了），看这四条：

1. **承诺兑现率**：她说「我记着了」之后，下次真的记得吗？
2. **纠错复现率**：被指出「你说错了」之后，同类问题还会错吗？
3. **事实一致性**：同一件事问两次，答案一样吗？（30 轮里第 6、16 轮故意重问，她两次一致）
4. **主动行为有没有前因**：她开口时，能不能说出「因为刚才 XX」？

## 9. 审计与动机（P1 / P2，2026-10-31 上线）

### 9.1 审计怎么用

每次走 Letta 的对话都会自动留痕，不需要额外开启（`behavior.letta.audit !== false`）：

1. **回复前**抓一份记忆块快照 → `data/letta-snapshots/snap-<时间>-<随机>.json`（自动只留最近 60 份）；
2. **回复后**再读一次块，算出「哪块改了 / 改了几字 / 几行」，连同「听到什么、说了什么、用了哪些工具」
   写进 `logs/letta-audit.jsonl`；
3. 群聊/私聊都在内，只把块的**前 120 字**存进账本（不存全文）。

指令：

- `/她改了啥` / `/她改了啥 10`：最近 n 次改动，格式 `· persona 改 +64 字（1 行）`，带前后片段；
- `/回滚`：列出最近 5 份快照（id / 时间 / 起因 / 各块长度）；
- `/回滚 snap-20261031T…`：把块恢复成那份快照，并写一条 `kind:'rollback'` 的审计行。

边界：回滚**只回滚记忆块**，不回滚对话历史（对话在 Letta 自己的库里，没有暴露删除接口）；
`safety` 块被改动会标成「只读块被改」——出现就说明有问题，别忽略。

### 9.2 动机接入怎么工作

```
scheduler.runImpulse()
  ├─ 冲动 < 阈值 / 静默 / 日上限 / 间隔 / 刚聊过  → 直接 return（这些判断一行没少）
  ├─ 过闸 → lettaTrial(conf.behavior.letta, conv)
  │     ├─ 不在白名单 → 走原来的 generateProactive
  │     └─ 在 → lettaWake({reason, hint, mood})
  │            reason = 「冲动攒到 61，阈值 58」
  │            hint   = 「最近主人说过：…」
  │            mood   = moodWord(agency.mood)
  │          ├─ 她回 SKIP  → 扣 25 冲动，trace `self-skip`
  │          ├─ 她说两句  → 拆气泡（最多 3 条）→ 发出去 → 扣 38、计次、记 awaiting
  │          └─ 连不上    → warn + 回落原来的主动大脑
```

她拿到的那条消息（`wakePrompt`）明确写着「这是系统提醒，不是主人在说话」「不想说就只回 SKIP」——
避免她把自己脑内的一句提醒当成主人说的话去回应。

### 9.3 还没做的

- 「承诺兑现」仍走原来的模板（没有接入 Letta）——承诺是硬约定，先不交给概率；
- 回滚粒度是「整块」，不能只撤销某一次改动；
- 两套记忆（云端 `memory.json` 与 Letta 块）依然不同步，切换前需要手动合并。
