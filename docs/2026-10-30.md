### v1.11.0 — 更像真人的六个零件（P0）

1. **内部标记清洗** `stripInternal()`：`<system_reminder>`、`DSML`/`tool_call` 标签、`[图:…]`、`【回复方式】`这类内部段落，
   出站 / 写记忆 / 拆气泡三处都过一遍，用户再也看不到这些。
2. **连发合并**：`behavior.coalesceMs = 1600`。你说「在吗」+「今天好累」，她只回一次，并且两条都当上下文。
3. **说话人画像** `profiles.mjs`：按 `群:用户` 记平均字数、爱提的词、是否爱 @ 人，注入 ≤3 行，零 token。
4. **心情进 prompt** `moodBrief()`：把 agency 的 valence/arousal/clingy 翻译成「语气方向」，不给数字。
5. **规矩硬约束**：`/规矩 别老说本鲸` 写进 `agency.rules`，和人格冲突时以规矩为准，最多 10 条，可 `/规矩 删 n`。
6. **用量账本** `usage.mjs`：每次调用记 `data/usage-YYYYMM.jsonl`（不记正文），`/用量`、`/余额` 可查。

参数同时改了：表情包概率私聊 `0.22`、群聊 `0.08`（原来 0.18/0.06），并且**挪到生成层掷骰子**——没资格就不给表情包清单，省 1.3k token/轮。

### v1.12.0 — 说多一点，追问要接

- 私聊：`ratePerHour 6→9`、`impulseThreshold 70→58`、`impulseCost 45→38`、`dailyLimit 5→8`、`minGapMin 50→35`。
- 群聊：`ratePerHour 3→6`、四档日上限 `100/40/20/6`、每小时 `15/10/4/2`、最小间隔 `75s/4min/15min/1h`、
  机会分门槛 `8/9/10/13`、冷清群开场间隔 `45→25` 分钟。
- **追问窗口**：`followUpMinutes = 12`。谁 @ 过她 / 引用过她，之后的 12 分钟里那个人再说话（不带 @），她也会接。
  这就是你截图里「答完一句就沉默」的问题的修法。

### v1.13.0 — 气泡不许切词

你截图里「…都认全了。 稻」/「穗加这脸…」是 `splitRough()` 按字数硬切的锅。
现在：≤40 字一律一条；40–120 字多数整条；>120 字且有两句读才拆；**只在标点处断**，默认上限从 6 降到 3。

### v1.14.0 — 语音

- 合成成功后**只发语音**，不再「语音 + 同样一句话」重复。
- `wantsVoice()` 认「语音呢 / 唱两句 / 念一下 / 发个语音」，命中就 `forced` 绕过概率必发；群里仍不发。
- `REPLY_STYLE` 里写明「你能发语音，别人要你说/唱时直接说，别声称自己只能打字」。

## 二、Letta：从「我们造人格」到「让她自己长」

### 2.1 为什么会转

你发的那条抖音（「不是按固定人设表演，而是给一个起点」）之后，我们的对比结论只有一句：
**差别不在记忆多少，而在「谁有权改写她是谁」。** 我们这边人格是受保护的先验（人设 + 界碑 + 规矩 + drift 闸），Letta 那边身份是**她自己能改写的状态**。

你选了后者（m06763）：「我倾向于使用 letta，使她能够自己更新自己的人格……我也想看到她自己会发展成什么样。」

三个边界当场定下：先本机跑通再决定上云；向量用本地 bge-m3；**只锁安全最小集**，其余全自由。

### 2.2 环境（Windows 本机，踩了不少坑）

- PyPI 上的 `letta` 已经是「Letta Code」，服务端要装 **`letta-nightly==0.11.5`**（要求 Python ≥3.11）。
- 本机只有 3.10 → 用 uv 装了独立 `cpython-3.12.10` 到 `letta-lab\python\`。
- 沙箱不允许「子进程再 spawn 子进程」，pip 的构建隔离全挂 → 手工打了 `Pysher`、`demjson3` 两个纯 Python wheel，
  再 `uv pip install --find-links wheels_local`。
- 装完还要补：`sqlite_vec`（Letta 的向量扩展，没被声明为依赖）、把 `pydantic` 降到 `2.11.9`（和 mcp 1.10.1 不兼容）。
- **四处补丁**（都在 site-packages）：`LETTA_DIR` 可配（沙箱写不进 `~/.letta`）、`deepseek_client` 漏了 `ChatMessage` 导入、
  `provider_type=deepseek` 那条分支会把回复当 JSON 解析（必失败）→ 改走 **OpenAI 兼容端点**、`start-letta.cmd` 里补 key 环境变量。

跑起来的样子：`letta server --port 8283`，数据 `letta-lab\letta-data\sqlite.db`，聊天入口 `chat.cmd`（`/块` 看记忆、`/想` 看内心独白）。

「说话直接，句子短，偶尔有点刺」「不确定就说不知道，不编记忆」——**这是它自己写的，不是我灌的**。

### 2.5 QQ 试运行（今晚收尾）

- 新增 `cloud/lib/letta.mjs`：把某个会话的消息转给 Letta，回复按换行拆成最多 3 条气泡。
- 桥上加了试运行路由：`behavior.letta = {enabled, baseUrl, agentId, convs[], timeoutMs, maxSegments}`，
  **凡是不在 `convs` 里的会话，一律照旧走原引擎**；Letta 连不上就回落，日志里会写「回落原来的大脑」。
- 连接方式：本机 `ssh -N -R 127.0.0.1:8283:…` 反向隧道（`tunnel.cmd`），服务器侧看到的就是 `127.0.0.1:8283`，不暴露公网。
- 已验证：
  - 私聊「你在干嘛」→ 3.1 秒，`刚把今天的事记进小本本里，正收拾着呢`；
  - 群聊 @ → 3 条气泡带引用；群聊不 @ 的追问（12 分钟窗口内）→ 也接了。
- 为了让群里「只有一个她」，试运行期间把 **S2 群主动插话（`proactive.group.enabled`）关掉了**，私聊主动不受影响。
