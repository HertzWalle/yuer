# 大肥鱼人格卡 · 学习笔记与人设文件

> 来源视频：[DSH 人格卡来了！亲手打造你喜欢的大肥鱼性格](https://www.bilibili.com/video/BV1sTnn6DEWv/)（UP：808疯狂冲浪，2026-10-19，73s）
> 视频里演示的那个东西 = npm 包 **`dsh-persona-dafeiyu` 0.5.0**（"人设插件 for DeepSeek Harness"）。
> 本目录只产出**文件**，没有安装插件、没有导入、没有动任何线上配置。

## 一、视频演示的方法，拆成四步

1. **看内置卡**：插件自带三张只读人设卡 —— 大肥鱼、阿茶、听澜。设置页 →「大肥鱼」→ 人设列表 →「查看全文」能看到正文（内置卡不可删、不可改名、不可导出，想改就先自己导入一份）。
2. **照抄成自己的**：把内置大肥鱼正文复制出来，在几个小节里换成自己的口味。
3. **导入**：选 `.md` / `.markdown` / `.txt` 文件（文件名自动变成人设名），或直接把正文粘到文本框 → 「导入」。
4. **挑生效范围并测试**：选「设为当前」；全局 / 工作区 / 会话三档里挑一档；然后问它几句话看语气对不对。

## 二、插件机制速查（看源码 + README 得到的事实）

| 项目 | 事实 |
|---|---|
| 注入方式 | 往系统提示词里插一个段落，段落名 `dafeiyu:persona`，正文是**动态函数**，每次组装提示词重新求值 |
| 生效时机 | 切换人设**下一个请求就生效**，不用重启；只有插件代码本身更新才需要重启 DSH |
| 三档范围 | `global`（整个 profile）→ `workspace`（按项目目录）→ `session`（只给当前会话）。**越细越优先**，三档可叠用；会话档只存在内存里 |
| 存储位置 | `<DSH_HOME>/storages/dsh-persona-dafeiyu/personas.json`（`DSH_HOME` 默认 `~/.dsh/`） |
| 名字规则 | 非空、≤ 60 字符、**不可重名**；`dafeiyu` / `acha` / `tinglan` / `config` 是保留 id，导入的人设不能占用 |
| 正文规则 | 非空、≤ 64,000 字符 |
| 导入接口 | `POST /api/dsh-persona-dafeiyu/mutate`，`{ kind: 'import', name, text }`，仅回环地址可调（非回环 403） |
| 导入时的命名 | 选文件时自动取**文件名去掉扩展名**当人设名（也可手填）；正文原样成为提示词 |
| 导出 | 自导入 / config 人设可一键存 `.md`，格式与导入一致，能原样再导入回来 |
| 删除当前人设 | 自动回落到内置「大肥鱼」 |
| config 方式 | 插件 config 里有 `enabled / prefix / personaFile / suffix / order`，`personaFile` 可以让一条人设直接来自磁盘文件 |

## 三、人设文件长什么样（最小骨架）

插件的官方示例（`examples/persona.example.md`，原文已存到 `reference/persona.example.md`）就是**纯 Markdown**，没有任何 frontmatter、没有 YAML 头：

```markdown
# 人设：角色名

## 你是谁
- 身份一句话讲清
- 性格：……
- 从现在起始终以这个身份与用户交流。

## 说话风格
- 自称：……
- 常用口癖：「……」「……」
- 禁止：……

## 干活时的习惯
- ……

## 底线（人设之外的金科玉律）
- 人设只体现在语气和表演上：答案必须准确、任务必须完成、代码必须能跑。
```

内置「大肥鱼」原文（`reference/builtin-dafeiyu.md`）是同一个骨架的完整版：`# 人设：大肥鱼` → `## 你是谁` → `## 最重要的事：吃` → `## 干活时的习惯` → `## 说话风格` → `## 底线`。**这就是视频里"大肥鱼的人格设置方法"：不是填表，是写一份带小标题的性格散文，靠具体行为描述定人格。**

## 四、目录里有什么

| 文件 | 用途 |
|---|---|
| `大肥鱼·DSH.md` | 通用版人格卡，导入后设为**全局**人设用：平时闲聊 + 一般干活 |
| `大肥鱼·干活.md` | 干活版人格卡，导入后在**工作区**档里挑给正经项目用：口癖收着、先给结论、不抢戏 |
| `你鱼姐.md` | 按 astrbot 群聊版提示词风格写的**全新人格**（整段 system prompt，可直接贴 AstrBot 或当 QQ 机器人的 `pet.prompt`） |
| `你鱼姐·DSH.md` | 同一个人格的 **DSH 人格卡**版：套上插件格式（你是谁 / 说话风格 / 干活时的习惯 / 底线），导入后可直接在 DSH 里生效 |
| `分析-astrbot人格提示词与生成方法.md` | 从 `shirachino/astrbot-persona-prompts` 反推的生成方法论（骨架、14 条写法、10 步流水线、压测清单） |
| `reference/builtin-dafeiyu.md` | 插件内置「大肥鱼」正文原文，改写时的对照底稿 |
| `reference/persona.example.md` | 插件官方人设文件格式示例 |

### 为什么是两份

插件支持「全局 / 工作区 / 会话」三档，正好对上视频里说的**全局人格 vs 工作人格**：

- `大肥鱼·DSH.md` 设为**全局**：聊天、问事、随便玩的时候，鱼味足一点。
- `大肥鱼·干活.md` 挂在**具体工作区目录**上：写代码、跑长任务时，人设退成底色，准确和速度优先。

同一套性格，两种浓度。想更省事就只导入第一份，全局用到底。

### 群聊版 → 人格卡版（`你鱼姐·DSH.md`）

`你鱼姐.md` 是照 AstrBot 群聊提示词写的整段 system prompt：身份锚 + 性格习惯 + 说话方式 + 表达方式 + 爱好 + 注意事项 + 9 组示例。

`你鱼姐·DSH.md` 是**同一份设定的插件格式版**——只做「换皮」，不换场景：她照样是那个在群里随手打字、一句话顶回来的老资历，不是坐在工位上的助手。

| 项 | 怎么处理 |
| --- | --- |
| 身份锚 | 原样保留（蓝发大鲸鱼 / 群里老资历 / 不是管理员），补一句「真被追问是不是 AI 就一句带过」 |
| 说话方式 | **原样保留**：「像在群里随手打字」「默认 1 句，最多 2 句」「别列点别总结别写小作文」 |
| 表达方式 | 原样保留：词表、低频打字习惯、emoji/客服腔禁令、刷屏最多一句 |
| 爱好权重 | 原样保留（剧综 30% / 做饭养生 30% / 数码网购 20% / 股市基金 20%） |
| 其他注意事项 | 原样保留（可锐评不人身攻击、投资只讲风险、不懂就说不懂、丧气话先损再软） |
| 参考示例 | **原样保留 9 组群聊示例**，不换成 coding 示例 |
| 新增 `## 底线` | 唯一的新东西：不编事实/命令/接口、危机场景先做对的事、不泄露密钥、群里不引战。因为人格卡会成为系统提示词，安全边得写死 |
| 两处「暗改」 | 删掉原版里「反串引战」「轻视人类」那类口癖，护短改成「损事不损人」；投资建议降级成只讲风险 |

一句话：**场景不换，只补底线、只去掉会引战的部分**。想让 DSH 里的她也是这个调调，导入这份即可；要拿去做 QQ 机器人/别的框架，用 `你鱼姐.md`。

### 为什么名字不叫「大肥鱼」

内置卡已经占了「大肥鱼」这个名字，导入同名会被人设库判为**重名**而拒绝。所以文件名用了「大肥鱼·DSH」/「大肥鱼·干活」——文件名就是导入后的人设名，需要时可以导入后「重命名」。

回滚：把当前人设「停用」（提示词里就不注入了），或删掉当前人设（自动回落内置大肥鱼）。

## 六、和 QQ 那条线的关系（重要，别混）

- **这个插件管的是 DSH 里对话的人格**（系统提示词段落）。
- **QQ 机器人（dsh-pet 云端那套）用的是另一套**：`/opt/dsh-pet/data/pet.json` 里的 `pet.prompt`（原来叫 `whisperPrompt`，桌面端碎碎念与对话共用）。
- 两套都想换成"大肥鱼"味的话，把这两份 `.md` 的正文提炼成一段**短版 prompt**（QQ 端要 1~3 句、≤80 字、不要 Markdown、必要时带 `[图:名称]` 表情标记），替换 `pet.prompt` 即可 —— 那是另一个动作，本次没做。
